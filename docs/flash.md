# Breed刷机教程
## 进入Breed
路由器断电，按住复位键，通电，等待指示灯闪烁，松开复位，访问 `192.168.1.1` 进入Breed控制台。

## 刷机步骤
1. 进入Breed → 备份EEPROM（一定要备份）
2. 固件更新 → 选择 `*‑sysupgrade‑bin.bin`
3. ❗**取消勾选保留配置，全新刷写**
4. 确认上传刷写，等待2‑5分钟，全程不要断电。
5. 刷完浏览器访问 `192.168.1.1`

## 注意
1. 只刷 sysupgrade‑bin 固件，不要刷其他格式。
2. 刷完如果打不开页面，清理浏览器缓存，检查电脑IP网段。
3. 登录后立刻设置root密码。
